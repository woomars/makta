# 막타

폭탄 카드로 서로 공격하며 손패를 먼저 비우는 카드 게임입니다. 각자 폰으로 하고, 방 번호를 넣거나 QR을 찍어 들어오며 빈자리는 봇이 채웁니다. 사람과 봇을 합쳐 2~10명까지 할 수 있습니다.

**플레이:** https://woomars.github.io/makta/

개인 재미를 위한 비상업 프로젝트입니다. 코드와 직접 만든 그림은 MIT 라이선스([LICENSE](LICENSE))이고, 그 밖의 자료는 아래에 적은 각 라이선스와 권리를 따릅니다. 라이선스 전문은 [vendor/LICENSES.md](vendor/LICENSES.md)에 있습니다. 소리는 Web Audio로 직접 합성했습니다.

**Last Hit** — attack each other with bomb cards and be first to empty your hand. Everyone plays on their own phone, joining by room number or QR; bots fill empty seats (2–10 players).
